基準値は〔付表２〕高等学校生適用欠課時数早見表（1学期13週／2学期まで27週／学年35週）の「超えた欠課時数」です。欠課時数がその数字以上になると単位不認定です。「あと◯時間」は基準の1時間手前まで欠課できる残り時間です（0時間＝あと1時間で不認定）。色: 緑＝余裕 / 黄＝残り2時間以内 / 赤＝超過。バックアップのファイルには呼び名が入るので、公開リポジトリにはアップロードしないでください。

GitHub同期の設定

データは、Private（非公開）のリポジトリの1ファイルに保存されます。アプリ本体の公開リポジトリとは別のものを用意してください。

トークンの作り方 GitHub右上のアイコン → Settings → 一番下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Expiration（期限）を決め、Repository access は「Only select repositories」でデータ用のPrivateリポジトリだけを選び、Permissions の Contents を「Read and write」にして作成します。表示されたトークンは一度しか見られないので、そのまま下の欄に貼り付けます。
